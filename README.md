## 🌟 專案緣起與自主特色

在營隊結業簡報中（第 15~18 頁）介紹的「無憂 APP 情緒觀察表」功能限制白名單登記（白名單 ONLY），且需透由各組組長開通與同步。

為了讓大家回到平時生活能**「覺察不斷線」**、自由分享給身邊的學生、家人、同修，並將所有私密的心靈對話與情緒日記**100% 完整備份在自己的電腦與手機硬碟**中，特此量身打造了這套**「獨立無憂情緒觀察表 Web/PWA 應用程式」**！

### ✨ 七大核心優勢
1. **完全自主，無白名單限制**：打開即用，不需課務組審核，沒有帳號綁定或過期停用風險。
2. **在手機上流暢執行 (PWA)**：支援 iPhone 與 Android 手機，可「加入主畫面」全螢幕運行，無網際網路亦可離線填寫！
3. **🎨 心靈塗鴉畫布 (自己畫 / upload照片 / 照相)**：
   - **自己畫**：直覺畫布，支援 8 種情緒色彩、筆觸粗細、橡皮擦、復原與畫紙底色切換。
   - **upload照片**：從手機相簿或電腦硬碟上傳照片，直接在畫布上塗鴉標註。
   - **照相**：手機相機一鍵即開即拍，現場影像無縫匯入畫布。
   - **無縫帶入觀察表**：塗鴉可直接作為觀察表的附件，並在清單中縮圖預覽與檢視。
4. **備份在自己的硬碟**：
   - 支援「一鍵下載完整 JSON 備份檔」到手機或電腦。
   - 支援「一鍵寫入本機 `backups/` 資料夾」（搭配本機伺服器）。
   - 隨時可從硬碟「還原備份」，資料絕不遺失。
5. **一鍵匯出 Excel 報表 (.xlsx)**：完全復刻簡報第 17 頁功能，一鍵產出包含「統計總覽」與「12 欄位明細」的綠色 Excel 活頁簿！
6. **完全復刻 1-12 欄位與夢幻薰衣草 UI**：

   - 彩虹粉彩串珠頂部標記、夢幻微光粒子背景與新擬物化（Neumorphic）溫潤卡片
7. **便於分享**：

## 🚀 快速開始使用

### 方式一：在電腦上雙擊啟動（最推薦，可同時提供手機連線）
1. 在資料夾中找到 **`啟動情緒觀察表.bat`** 並直接滑鼠雙擊。
2. 系統會自動啟動本機伺服器，並於預設瀏覽器打開：
   - 電腦本機網址：`http://localhost:8080`
   - 手機連線網址：`http://[你的區域IP]:8080`（例如 `http://192.168.2.12:8080`）
3. 控制台會顯示連線資訊，手機只要連線至同一 Wi-Fi，用相機掃描或輸入網址即可立即使用！

### 方式二：純離線直接點開
- 就算沒有執行 Python 或伺服器，也可以直接雙擊 **`index.html`**，直接在 Edge、Chrome 或 Safari 瀏覽器中執行！所有資料自動保存在瀏覽器 IndexedDB / LocalStorage 中。

## 📱 手機執行教學（加入主畫面成為 App）

本程式已配置完整 Progressive Web App (PWA) 技術，手機打開後可加入主畫面：

### 🍎 iPhone (iOS Safari)
1. 在手機 Safari 瀏覽器中打開 App 網址。
2. 點擊螢幕下方正中間的 **「分享」按鈕**（方形帶向上箭頭 ⬆️）。
3. 向下滑動選單，點選 **「加入主畫面」**（Add to Home Screen）。
4. 點擊右上角「新增」。手機桌面即會出現「情緒觀察」圖示，點開即可像原生 App 一樣全螢幕、離線填寫！

### 🤖 Android (Google Chrome)
1. 在手機 Chrome 瀏覽器中打開 App 網址。
2. 點擊右上角的 **「⋮」選單**。
3. 點選 **「安裝應用程式」** 或 **「新增至主螢幕」**。
4. 完成後即可在手機桌面點擊開啟，斷網離線亦可使用！

## 📋 情緒觀察表 1-12 完整欄位

依據簡報第 16 頁規劃：**除了觸發點、好像\確立的事實、今日評價、事件這 5 個欄位為文字外，其餘皆支援選單標籤與滑桿**：

| 編號 | 欄位名稱 | 類型 | 說明與預設範例 |
| :---: | :--- | :---: | :--- |
| **1** | **事件** | 文字/時間 | 客觀描述發生什麼事（人、事、時、地） |
| **2** | **觸發點** | 文字 | 觸發我情緒的境（一句話、眼神、動作） |
| **3** | **身體反應** | 選單標籤+自訂 | 抿嘴、皺眉、倒吸一口氣、嘆氣、心跳加快、胸悶、胃緊縮... |
| **4** | **心裡自然流露的話** | 選單標籤+自訂 | 啊！、什麼？、快遲到了！、你在說什麼？、好緊張、氣死人了！... |
| **5** | **情緒類別** | 選單標籤+自訂 | 訝異、擔心、疲累、驚嚇、難過、壓力、懊悔、緊張、煩躁、傻眼... |
| **6** | **情緒指數** | 互動滑桿 | 針對選取的每種情緒評定 0~100 強度數值 |
| **7** | **情緒落地方式** | 選單標籤+自訂 | 按摩臉頰、敲胸、深呼吸、按摩腸胃、拔菜、拔草、行走、腳踩大地... |
| **8** | **情緒落地時機** | 選項 | 當下落地 / 事後落地 / 尚未落地 |
| **9** | **落地後情緒指數** | 互動滑桿 | 落地後情緒舒緩數值（0~100），自動計算舒緩幅度 |
| **10** | **好像的事實** | 文字 | 杏仁核自動加工的腦補、假相（如：「他一定在針對我」） |
| **11** | **確立的事實** | 文字+核對 | 冷靜查證後的真相，並核對假相錯誤率（完全錯誤 / 部分錯誤 / 符合事實） |
| **12** | **今日評價** | 文字 | 對自己的肯定、溫柔鼓勵、善意看見、觀功念恩 |

## 💾 資料備份與安全性

- **100% 本地儲存**：資料儲存在您自己的電腦或手機中，不經過任何第三方雲端伺服器，最高規格保障個人覺察日記隱私。
- **隨時備份到硬碟**：
  - 進入「資料」頁籤，點選 **「下載完整備份檔 (JSON)」**，可將檔案存入隨身碟、硬碟備份資料夾或雲端隨身硬碟。
  - 亦可點選 **「一鍵寫入電腦專屬目錄」**，將備份自動歸檔在 `backups/` 資料夾內。
- **隨時還原**：更換手機或電腦時，只需點選 **「從硬碟還原備份檔」**，選取先前存下的 JSON 檔即可瞬間還原！
